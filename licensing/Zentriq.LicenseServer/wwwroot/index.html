Offline activation

For Zentriq servers without internet access. Servers that can reach this site activate directly from Licensing › Activate online with the license key.

  1. On the Zentriq server, open Licensing › Offline activation and download the activation request file.
  2. Bring the file to a computer with internet access and upload it here with your license key.
  3. Download the license file and import it under Licensing › Offline activation › Import license.
