Offline activation

For Zentriq servers without internet access. Servers that can reach this site activate directly: Licensing › Import license file (validated online).

  1. On the Zentriq server, open Licensing › Offline activation and download the activation request file.
  2. Bring the file to a computer with internet access and upload it here with the license file you received from Zentriq (or your license key).
  3. Download the license file and import it under Licensing › Offline activation › Import license.
